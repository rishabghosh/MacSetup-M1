# Entertainment apps

[All categories](install.md)

## Homebrew script

```bash
./install-entertainment.sh
```

Installs VLC, Discord, Brave Browser and Proton VPN.

## Install by hand

| App | From | Where to get it | Homebrew instead |
|---|---|---|---|
| Telegram | ⬇️ Website | https://macos.telegram.org/ (the native macOS app, not Telegram Desktop) | `brew install --cask telegram` (the same native app) |
| uTorrent Web | ⬇️ Website | https://www.utorrent.com/web/ | None, no cask exists |
| VMR Connect (VLC Mobile Remote) | ⬇️ Website | https://www.vlcmobileremote.com/ | None, no cask exists |
| Screen Mirror to TV & Device | 🛒 App Store | https://apps.apple.com/app/id1496988766 | `mas install 1496988766` (free) |
