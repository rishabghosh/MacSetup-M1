# Gaming apps

[All categories](install.md)

## Homebrew script

```bash
./install-gaming.sh
```

Installs the Epic Games Launcher, Steam, GeForce NOW, BlueStacks Air and GameHub. The BlueStacks cask runs the official installer, which also adds the BlueStacks Air Multi-Instance Manager and BlueAI.

## Install by hand

Nothing. Every gaming app comes from the script.
