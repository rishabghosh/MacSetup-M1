# Office apps

[All categories](install.md)

## Homebrew script

```bash
./install-office.sh
```

Installs Slack, Microsoft Teams, Zoom, Microsoft 365 (Word, Excel, PowerPoint, Outlook, OneNote and OneDrive), WPS Office, Google Chrome and Microsoft Edge.

Things to know:

- Microsoft Teams and Microsoft 365 come as installer packages, so each asks for your password.
- Open Word, Excel or PowerPoint once and sign in to activate Microsoft 365.
