# Office apps

[All categories](install.md)

## Homebrew script

```bash
./install-office.sh
```

Installs Slack, Zoom, Claude, ChatGPT and Brave Browser.

## Install by hand

| App | From | Where to get it | Homebrew instead |
|---|---|---|---|
| WPS Office | ⬇️ Website | https://www.wps.com/download/ | `brew install --cask wpsoffice` |
| Google Chrome | ⬇️ Website | https://www.google.com/chrome/ | `brew install --cask google-chrome` |
| Safari | 🍎 Built in | Nothing to install | None, it's part of macOS |
