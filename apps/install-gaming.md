# Gaming apps

[All categories](install.md)

## Homebrew script

```bash
./install-gaming.sh
```

Installs the Epic Games Launcher.

## Install by hand

| App | From | Where to get it | Homebrew instead |
|---|---|---|---|
| Steam | ⬇️ Website | https://store.steampowered.com/about/ | `brew install --cask steam` |
| GeForce NOW | ⬇️ Website | https://www.nvidia.com/en-us/geforce-now/download/ | `brew install --cask nvidia-geforce-now` |
| BlueStacks Air | ⬇️ Website | https://www.bluestacks.com/mac (also installs the Multi-Instance Manager) | `brew install --cask bluestacks` (runs the official installer, and includes BlueAI) |
| BlueAI | ⬇️ Website | Made by BlueStacks (now.gg). Check whether BlueStacks installed it; otherwise look on https://www.bluestacks.com | Comes with the `bluestacks` cask |
| GameHub (GameSir) | ⬇️ Website | https://www.gamesir.com (the Mac version is in beta) | `brew install --cask gamehub` (same version as the old Mac's, 0.8.613) |
| Rise of the Tomb Raider | Mythic launcher | Install Mythic from https://getmythic.app, sign in to the store you bought the game on, and download it again | `brew install --cask mythic`, then download the game again inside Mythic |
