# Utils apps

[All categories](install.md)

## Homebrew script

```bash
./install-utils.sh
```

Installs 1Password, ProtonVPN and Macs Fan Control.

## Install by hand

| App | From | Where to get it | Homebrew instead |
|---|---|---|---|
| iStat Menus 7 | 🛒 App Store | https://apps.apple.com/app/id6499559693 | `mas install 6499559693` (paid, already purchased). Not the `istat-menus` cask: that's Bjango's website version, and your App Store license won't unlock it |
| OS Cleaner Pro | 🛒 App Store | https://apps.apple.com/app/id1084211765 | `mas install 1084211765` (free) |
| Send Anywhere | ⬇️ Website | https://send-anywhere.com/ | `brew install --cask send-anywhere` |
| Vorssaint | ⬇️ Website | https://github.com/vorssaint/vorssaint-utils (Releases) | `brew install --cask vorssaint` |
